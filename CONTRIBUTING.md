# Contributing to the documentation

This repository records observed current state, not a target architecture. Keep source references repository-relative, identify the symbol or line where practical, and mark claims as **Implemented**, **Configured**, **Inferred**, **Not found**, or **Unknown**.

Do not add credentials, database dumps, or copied production data. Verify links and Mermaid syntax before proposing a documentation change. Update the snapshot and evidence index when source revisions change.
