# Known gaps and risks

Severity is an engineering assessment, not an exploit claim. “Confirmed” indicates direct code evidence; recommendations are not current behavior.

| Finding | Severity | Component | Evidence | Impact | Status / recommended remediation |
|---|---|---|---|---|---|
| Gateway rate limiter deliberately fails open when Redis unavailable/errors | Medium | gateway | `cmd/server/main.go:35-39`; `rate_limit_middleware.go:75-79,90-95` | abuse protection is absent during Redis outages | Confirmed. Choose explicit fail-closed/degraded policy and monitor Redis health. |
| gRPC identity service binds `:50051` and inspected client/server show no transport/auth configuration | High | identity/academic | identity `cmd/server/main.go:135-150`; academic `pkg/grpcclient/tenant_client.go` | tenant data/status interface can be exposed/intercepted on an untrusted network | Confirmed for shown code. Restrict network, use mTLS and service authentication. |
| Most route groups require a JWT but no general permission-enforcement middleware is registered | High | identity/academic/billing/gateway | service route blocks and gateway router; permissions are data/cache only | authenticated roles may reach operations unless individual handler/use-case checks intervene | Confirmed middleware gap; per-resource exposure varies. Add centralized authorization and tests. |
| Web proxy performs only an optimistic JWT shape/expiry check, not signature validation | Medium | web | `kelolakelas-web/proxy.ts`; identity `pkg/jwt/jwt.go` remains the validation authority | a forged but structurally valid cookie can still change the initial navigation decision; backend rejects it on protected API calls | Confirmed. Malformed/expired cookies are cleared and redirected to login; cryptographic validation remains a follow-up. |
| Academic activation can remain unavailable until the durable retry limit is reached | Medium | billing/academic | billing `payment_reconciliations`, `reconciliation_worker.go`; academic `ActivateEnrollment` | paid transaction may remain `reconciling` or `terminal_failed` and needs operator follow-up | Confirmed residual risk. Automatic retry and observable state are implemented; refund automation and renewal reconciliation remain out of scope. |
| Subscription worker is in-process with no leader election or distributed lock found | Medium | billing | billing main `:103-105`; `subscription_worker.go` | multiple replicas could process the same due work | Inferred from code. Introduce singleton scheduling/locking and execution telemetry. |
| Health checks report process status only | Low | all Go services | gateway router, each `cmd/server/health.go` | orchestrator may mark services healthy while dependencies are unavailable | Confirmed. Add readiness dependency checks and separate liveness/readiness. |
| No metrics/tracing, deployment/IaC/CI, or verified backup/runbook assets found | Medium | workspace | repository inventory/search | operational diagnosis and recovery cannot be established from code | Not found. Add controlled operational artifacts and observability. |
| Stale `Tutorin` naming and generated copied Swagger coexist with KelolaKelas code | Low | web/docs | web `package.json`, layouts, `_docs/api/*`; service Swagger | operator/client confusion and stale contracts | Confirmed. Regenerate docs from current services and complete branding migration. |

Additional observations: service CORS only exists at the gateway; direct service exposure must be controlled by deployment (currently **Unknown**). Default DB SSL mode is `disable`, appropriate only for trusted local connections. No refresh/logout/password-reset/MFA endpoints were found.
